# Inside the Mind of SABZ

A cinematic live visualization of the real trained DQN brain
(18 inputs -> 64 -> 64 -> 2 outputs, 5,506 parameters) thinking
through 56 seconds of real simulation.

**What you see is real:** every neuron brightness is the actual
forward-pass activation of `sabz_dqn_best.npz` on simulator states.
The connection web is drawn from the real weight magnitudes.
Q-values, decisions, queues and delays are the genuine model outputs.

**Run:** just open `index.html` in Chrome. No server needed.
Everything (data + weights) is inlined in the single file.

**Controls:** Space = pause, 1/2 = speed, R = restart,
drag the timeline to scrub.

Generated by `gen_mind_data.py` (sim + brain), assembled by `build.py`.
